# Pinterest 스페인어 어휘 이미지 수집기

Pinterest에서 스페인어 어휘 관련 이미지(인포그래픽·일러스트)를 주제별로 검색하고,
페이지에서 이미지 주소를 자동 수집해 원본 해상도로 한 번에 ZIP 다운로드하는 도구입니다.

**사이트:** https://yalli2.github.io/pinterest_search/

## 사용 순서
1. 어휘 주제 버튼(가족·음식·색깔·동사 등 22개) 또는 직접 검색어로 Pinterest 검색 탭 열기
2. 수집기 코드 복사 → Pinterest 탭에서 F12 → Console에 붙여넣고 Enter (자동 스크롤 후 주소 수집·클립보드 복사)
3. 사이트 3단계에 붙여넣고 썸네일로 필요한 이미지만 선택
4. ZIP 일괄 다운로드 (차단 시 .txt 목록 / download.sh 스크립트 제공)

## 저작권
수집 이미지는 각 제작자에게 저작권이 있습니다. 수업 참고·개인 학습용으로만 사용하고
재배포·상업적 사용은 하지 마세요.
