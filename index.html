2

이미지 주소 수집

Pinterest 탭에서 수집기를 실행하면 이미지 주소가 클립보드에 복사됩니다
📌 Pin 수집기 (북마크바로 드래그)
방법 A (북마크릿) — 위 빨간 버튼을 브라우저 북마크바로 드래그 → Pinterest 검색 탭에서 클릭.
방법 B (콘솔, 가장 확실함) — [수집기 코드 복사] → Pinterest 탭에서 F12 → Console 탭 → 붙여넣고 Enter. (Chrome이 경고하면 allow pasting 입력 후 Enter)

대기 중

  
ZIP이 실패하면? Pinterest 이미지 서버는 브라우저의 교차 출처 요청을 막습니다. 이 사이트는 이미지 프록시를 자동으로 시도하지만, 그래도 막히면 [Windows 일괄 다운로드(.bat) 저장]을 누르세요. 받은 download.bat을 원하는 폴더에 두고 더블클릭하면 pinterest_vocab 폴더에 전부 저장됩니다. (Windows 10/11은 curl이 기본 내장되어 있어 추가 설치가 필요 없습니다.)

  
저작권 안내 — 수집한 이미지는 각 제작자에게 저작권이 있습니다. 수업 내 참고·개인 학습용으로만 사용하고, 교재·홈페이지·SNS 등에 재배포하거나 상업적으로 사용하지 마세요. 필요하면 수집한 이미지를 참고 자료로만 보고 직접 제작한 그림/사진으로 대체하는 것이 안전합니다.
